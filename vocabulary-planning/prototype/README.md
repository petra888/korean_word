# 학습 흐름 클릭 시제품 v10 · 담당 학생 명단과 학생별 관리

`pilot-flow.html`은 개발 전 수업·화면 검토용 HTML입니다. 같은 폴더의 `assets/` 일러스트 열한 장과 함께 사용합니다. 고정된 학생·교사 테스트 계정으로 로그인합니다. 서버 인증·권한 보안·서버 저장은 구현 전이며, 학원·학생·교사는 가상입니다.

## 디자인 선택

상단의 **디자인 1 · 상상 숲**, **디자인 2 · 미래 도시** 버튼은 로그인 전후 모두 사용할 수 있습니다. 새 방문자의 기본값은 디자인 2이며 `vocabulary-design-v1`에 선택을 저장합니다. 잘못된 값은 기본값으로 처리하며, 저장 실패 시 현재 창에 적용하고 안내합니다. 같은 브라우저의 다른 탭에서도 디자인 선택이 동기화됩니다.

디자인 1은 민트·크림·세이지, 둥근 카드와 버튼, 숲·책 정원·토끼의 작문 정원·교사 식물 작업실을 사용합니다. 디자인 2는 푸른 유리·은백색·청록빛·주황 포인트, 각을 살린 카드와 버튼, 미래 도시·지식 관측소·창작실·교사 관제실을 사용합니다. 색만 바꾸지 않고 배경·테두리·표·입력창·단계 표시·아이콘·차트·메뉴와 화면별 일러스트를 함께 바꿉니다. 평가 결과의 오답 빨간색은 두 디자인에 공통입니다.

전체 화면 풍경은 스크롤 중에도 고정되고 800px 이하에서 세로 배경을 사용합니다. 디자인 1의 잎·나비·빛, 디자인 2의 탐사 드론·빛 신호·광원은 장식 레이어입니다. `배경 움직임 끄기/켜기`는 두 디자인에서 공유하며 기존 `vocabulary-forest-motion-v1` 선택을 유지합니다. 기기의 동작 줄이기와 비활성 탭에서는 움직임을 멈춥니다.

디자인 전환은 학습 화면을 다시 렌더링하지 않습니다. 입력 중인 로그인 정보와 작문·교사 코멘트, 아직 제출하지 않은 문제 선택, 현재 학습 위치를 유지하며 학습 저장 기록의 시각·revision도 변경하지 않습니다. 디자인 선택은 로그인·로그아웃과 교사의 학습 기록 초기화 후에도 유지합니다.

[화면과 검증](../qa/release-readiness/designs/README.md)을 참고하세요. 모든 일러스트·글꼴은 외부 서비스에 의존하지 않으며 11장 WebP는 합계 약 2.8MB입니다. 활성 디자인의 화면 크기에 맞는 전체 배경 한 장과 해당 화면 일러스트를 표시합니다. 학부모 인쇄 자료에는 디자인 선택·일러스트·움직임·화면 메뉴를 제외합니다.

## 테스트 로그인

| 로그인 유형 | 아이디 | 비밀번호 |
| --- | --- | --- |
| 학생 · 이지우 | `test1` | `test1` |
| 학생 · 김도윤 | `test3` | `test3` |
| 학생 · 박서연 | `test4` | `test4` |
| 교사 | `test2` | `test2` |

아이디와 비밀번호는 공백 없이 입력합니다. 학생은 명단의 `test1`·`test3`·`test4`, 교사는 `test2`입니다. 이메일·구글 연동은 없습니다. 계정 표기 변경 후 기존 로그인 세션은 다시 로그인하며 학습 기록은 유지합니다.

학생은 자신의 데모 학습 화면에 진입합니다. 교사는 먼저 담당 학생 명단을 보고 이름을 선택하면 해당 학생의 기록·작문 검토·부모 자료 화면에 진입합니다. 이름·아이디·반 검색과 반 필터, 실제 제출 진행과 최신 작문 버전 검토 대기 수를 제공합니다. 명단 복귀와 관리 페이지의 뒤로가기를 지원하며, 교사 새로고침은 명단으로 돌아갑니다. 학생을 다시 선택하면 저장된 관리 페이지를 엽니다. 마스터 로그인은 현재 구현되어 있지 않습니다. 화면 상단의 무인증 역할 전환 버튼을 제거했습니다. 계정을 바꾸려면 로그아웃 후 해당 유형으로 다시 로그인합니다. 데모 JSON 내보내기와 기록 초기화는 교사 화면에서 제공합니다.

세션은 `sessionStorage`에 역할·아이디·만료 시각만 저장하며 비밀번호는 저장하거나 학습 기록·호스트 상태·JSON 내보내기에 넣지 않습니다. 최대 8시간 동안 같은 탭에서 새로고침해도 로그인을 유지합니다. 세션 저장이 차단되면 현재 창에서 사용하되 새로고침 후 다시 로그인하도록 안내합니다. 로그아웃은 열려 있던 교사 자료를 지우고 학습 기록은 유지합니다. 학생과 교사는 같은 브라우저의 해당 가상 학생 기록을 함께 확인하며 다른 기기 간 공유는 구현 전입니다. `studentId`와 학생별 저장 키로 답안·작문·교사 코멘트·부모 자료·복구 기록을 분리합니다. 기존 이름 없는 v2 기록과 v1 이력은 이지우 `test1`에만 이어받으며 다른 학생에게 복사하지 않습니다. 학생 전환은 미저장 메모를 현재 창에 보관하고 인쇄·JSON 패널을 지웁니다. 초기화·JSON·부모 출력은 선택한 학생만 대상으로 합니다.

계정 검사는 브라우저에서 실행되는 테스트 기능입니다. 실제 학생 서비스의 보안 인증·서버 권한을 대신하지 않습니다. **사용자가 배포를 요청할 때까지 로컬 변경으로 보관하며 `main`에 푸시하지 않습니다.**

[학생별 관리 검증](../qa/release-readiness/multi-student/README.md)과 [실제 Chromium 검증](../qa/release-readiness/login/browser-results.json)에서 로그인부터 학생 학습·교사 검토까지 확인했으며, [VM 검증](../qa/release-readiness/login/vm-results.json)은 세션 만료·손상·저장 실패·역할 변경을 검사합니다. 실제 기기·실제 인쇄는 보류합니다.

배포 전 추가 점검에서 손상된 보기 순서가 중복된 오답4개를 표시하는 복구 누락을 보완했습니다. 정상 보기 순서와 기존 답안·작문은 유지하며, 손상 원문을 보관하고 해당 보기 순서만 다시 생성합니다. [현재 검증](../qa/release-readiness/validation-summary.json)과 [테스트 배포 순서](../documents/test-deployment.md)를 확인하세요.

2026년 10월 9일 개정: 2단계의 정답 1개와 서로 다른 오답 3개는 모두 1단계 진단에 나온 10개 단어로 구성합니다. 정규·보충 연습 90문항에 적용하며 보기 순서는 섞어 저장합니다. 기존 기록의 미제출 문항과 재시도에는 새 보기를 적용하고, 이미 제출한 첫 답·원문 문항·작문·교사 평가는 보존합니다. 이전 보기의 미제출 선택은 해제하여 새 보기에서 다시 고르게 합니다. [변경 검증 결과](../qa/release-readiness/diagnostic-choices-regression-results.json)를 확인하세요.

## 이번 흐름

1. **뜻 연결 진단:** 왼쪽은 교재 수록 순서의 10개 뜻, 오른쪽은 순서를 섞은 단어 카드입니다. 끌어 놓기와 단어·뜻 버튼 선택을 함께 지원합니다. 한 단어는 한 행에만 배치되고 중복 이동은 교환으로 처리합니다.
2. **모르겠음과 답 공개:** 모르겠음을 누른 행은 올바른 단어를 자동 배치하고 모름으로 고정합니다. 최초 공개 직전에 다른 행의 배치를 기록합니다. 공개 뒤에 처음 배치·변경해 맞힌 단어는 애매함으로 분류하고 재확인 상태를 남깁니다. 자동 배치 정답은 진단 정확도에서 제외합니다. 나머지 배치는 전체 진단 제출 전 변경할 수 있고, 제출 뒤 최초 분류는 유지합니다.
3. **이해·추론:** 진단에 따른 모름 60%·애매함 30%·앎 10% 비중으로 객관 문항 **10개**를 배정합니다. 연습은 단어당 9개로 총 90개이며 측정·기간 복습을 합친 객관 은행은 160개입니다. 첫 회차의 분류 쏠림(모름 1·앎 9 등)도 10문항을 공급하고, 후속 회차에서 새 문맥이 소진되면 보완 필요를 안내하고 시작을 보류합니다. 빈 그룹은 제외하고 최대 나머지 방식으로 정수 배분합니다. 10개는 섞어서 연속 출제합니다. 문제 화면에 목표 단어 제목, 뜻풀이 카드, 배정 그룹을 제시하지 않습니다. 보기 순서도 섞어 저장하며 고정 옵션 ID로 채점합니다.
4. **표현·수정:** 객관 연습 다음에는 교재 순서 **10개 단어 전부 한 문장씩** 작성합니다. 전수 작문 10개는 60·30·10 배분의 밖입니다. 각 문장을 개별 제출할 수 있어 일부 초고는 먼저 교사가 검토하고, 남은 초안은 이어서 작성할 수 있습니다. 모두 작성했다면 남은 문장도 한 번에 제출할 수 있습니다. 모든 초고를 제출해야 기간 전체 복습으로 이동합니다. 교사 확인 대기는 복습을 막지 않습니다.
5. **교사 확인:** 교사가 정답·오답·검토(애매) 중 하나의 일반 버튼을 선택합니다. 같은 버튼을 다시 눌러도 해제되지 않습니다. 작문 정답과 같은 학습 묶음의 해당 단어 객관 첫 답이 1개 이상이며 모두 정답이면 자동 앎입니다. 작문 오답은 모름, 작문 검토(애매)는 애매함입니다. 작문이 맞아도 객관 첫 오답이나 객관 미배정·미응답이 있으면 애매함으로 재확인합니다. 힌트는 도움 기록으로 남기고 자동 앎을 막지 않습니다. 적절한 동사 활용형과 조사 변형을 허용합니다.
6. **버전별 재평가:** 교사는 초고·수정본 중 평가할 버전을 직접 선택합니다. 미확정 판정·코멘트·수동 다음 분류는 제출본마다 따로 보존해 버전을 왕복 선택해도 작성 내용을 복원합니다. 선택한 원문 버전과 작문 판정·자동 분류·근거를 함께 보관합니다. 학생 수정만으로 그룹을 승격하지 않습니다. 최신 수정본이 미확정이면 이전 확정 판정의 근거 버전을 표시하고 재확인 대기를 명시합니다.
7. **다음 배정:** 자동 그룹을 미리 보여주며 교사는 앎·애매함·모름으로 조정할 수 있습니다. 조정 이유와 학생 코멘트는 선택입니다. 작문 판정을 바꾸면 조정값을 지우고 새 자동 그룹으로 돌아갑니다. 같은 버튼을 다시 누르면 조정값도 유지합니다. 단어별 최신 교사 확정 판정이 최초 진단과 객관 응답의 자동 재확인 분류보다 우선합니다. 교사 판정 이후 추가 오답은 재확인 필요로 표시합니다. 이미 배정한 문항의 그룹과 진행 중인 전체 복습의 대상·응답을 다시 계산하지 않습니다.
8. **전체 복습:** 주간·월간·분기는 각 시작 시 실제 객관 첫 답·초고 제출의 고유 의미 ID를 고정합니다. 모든 대상에 새 문맥을 한 개씩 제시하고 5개씩 쉬며 이어갈 수 있습니다. 전체 확인 후에 최신 판정을 반영한 새 보충 계획을 만듭니다. 같은 데모 기록으로 기간 흐름을 모의하며 실제 달력별 집계·스케줄링은 구현하지 않았습니다.
9. **교사·학부모 자료:** 종합 평가와 부모 메시지를 직접 작성·확정합니다. 부모 출력은 단어별 최초 진단·교사 확정·다음 배정과 판정 근거 버전, 복습 진도, 확인한 작문과 확정 문구를 포함합니다. 내부 지도 메모는 제외합니다. 자동 발송하지 않습니다.

## 교사 학습·복습 기록 표시

정규·보충 객관 기록의 학생 첫 답은 정답을 청록색, 오답을 빨간색으로 표시하고 정답·오답 글자를 함께 제공합니다. 미제출은 중립색으로 구분합니다. 주간·월간·분기 요약의 오답 단어 목록도 빨간색이며, 펼칠 수 있는 `복습 답안 상세`에서 기간별 학생 선택 답안을 확인합니다. 재시도 정답이 최초 오답의 기록이나 색을 바꾸지 않습니다.

## 도넛 차트와 부모 자료

- 교사 평가 화면과 부모 출력 자료 상단에 같은 집계 함수로 만든 SVG 도넛 두 개를 제공합니다. 단어 이해는 앎·애매함·모름·교사 확인 대기, 작문 평가는 정답·오답·검토(애매)·평가 대기입니다. 개수와 비율을 문자 범례로 함께 표시하고 중심에는 고유 대상 단어 수를 표시합니다.
- 분모는 현재 교재 묶음 WORDS의 고유 의미 ID입니다. 같은 의미의 다른 표제어, 반복 작문·수정·재평가는 분모를 늘리지 않습니다.
- 이해 도넛은 최신 교사 확정 분류만 반영합니다. 교사 확인 전 항목은 회색 대기이며 최초 진단은 아래 단어별 표에서 확인합니다. 레거시 명시 이해 그룹은 기존 교사 확정으로 인정하지만 숫자 배점만 있는 기록은 새 작문 판정으로 환산하지 않습니다.
- 새 수정본이 아직 검토되지 않았으면 기존 확정 분류와 작문 판정을 유지하고 수정본 재검토 대기 수를 별도로 보여줍니다.
- 정규 객관 연습의 완료·미완료와 고유 대상 단어의 작문 제출 진도를 구분합니다. 보충 활동은 기존 별도 집계에 남깁니다. 계획이 생성되지 않은 정규 객관 진도는 0/0입니다.
- 중간에는 복습 후보와 수정본 확인 대기를, 하단에는 교사 종합 평가와 확정 부모 메시지를 둡니다. 60·30·10은 다음 학습 배정 원칙으로 따로 표시하고 실제 이해 분포에 섞지 않습니다.
- 교사가 자료를 확정할 때 차트 스냅샷을 기록합니다. 같은 학생·동일 고유 의미 대상·동일 집계규칙의 이전 확정 스냅샷이 있을 때만 아는 단어 증감을 표시합니다. 첫 자료나 기준이 다른 자료는 비교 기준 없음으로 표시하며 임의의 주간 성장률을 만들지 않습니다.
- 앱 인쇄 버튼과 브라우저의 일반 인쇄(Ctrl+P)는 인쇄 직전에 현재 부모 자료를 다시 생성합니다. 최초 인쇄나 데이터 변경 뒤 인쇄에서도 현재 대상·확정 문구를 사용하고 내부 메모는 제외합니다.
- 도넛은 외측·내측 호를 가진 명시적 SVG 채움 패스로 그려 원의 파선 분할을 지원하지 않는 문서 렌더러에서도 분할을 유지합니다. 진도 막대도 SVG 채움 속성을 사용하여 인쇄 배경색 설정에 의존하지 않습니다. 실제 브라우저 인쇄 검증은 환경 제약으로 미실시입니다.

## 뒤로가기와 기록

- 상단 뒤로가기는 학생·교사별 이동 기록을 사용합니다. 교사의 기록·작문 검토·부모 자료 이동과 학생 단계 이동을 각각 보존합니다.
- 객관 미제출 선택, 힌트, 첫 응답과 재시도, 작문 초고·제출·수정·교사 확인을 보존합니다. 재시도 중 답을 선택한 뒤 이전 화면으로 이동해도 편집 상태·선택·제출 동작을 함께 복원합니다. 뒤로 이동하거나 재시도·수정해도 처음 제출한 활동을 새 활동으로 세지 않습니다.
- 한 정규 회차는 객관 10개 + 전수 작문 10개, 총 20개의 서로 다른 활동입니다. 교사는 객관 배분과 작문 제출을 분리해 집계합니다. 단어 수, 활동 수, 확인 진도와 정답률은 서로 다른 지표입니다.
- 단어를 임의로 선정하지 않습니다. 내장 콘텐츠는 원문 `source_order`에 따라 정렬합니다. 진단의 뜻과 전수 작문은 교재 순서를 유지하며 진단 단어 카드·혼합 문항·보기만 섞습니다. 콘텐츠는 교사 최종 승인 전 초안입니다.
- 브라우저가 허용하면 `localStorage`에 데모 기록을 저장하고 사용 가능한 호스트에서는 `window.openai.setWidgetState`를 시도합니다. `openai:set_globals`의 공유 상태는 revision과 수정 시각으로 최신 여부를 비교합니다. 오래된 상태와 시각·revision이 같은 다른 상태는 진행 중 로컬 입력을 덮어쓰지 않습니다. 더 최신인 호환 상태만 수신하며 수신 중 호스트 상태를 다시 쓰지 않습니다. 로컬 저장과 호스트 저장 성공·실패를 따로 안내하고, 다음 저장이 성공하면 해당 실패 경고를 해제합니다.
- 저장 형식은 **v2**입니다. 기존 v2의 답안·초고·수정본은 유지합니다. 복원 시 중첩 배열·객체·인덱스와 제출본 참조를 검사하며, 손상 원문은 복구 기록으로 격리해 JSON에 포함합니다. 손상 원문의 별도 보존이 실패하면 기본 저장값을 덮어쓰지 않고 안내합니다. 이미 배정된 과거 문항의 내용·정답 기준은 재현용으로 보존하고 새 160문항 은행의 신규 배정과 구분합니다. 과거 배점 기록은 새 작문 정답·오답으로 자동 환산하지 않습니다. 과거 교사가 명시한 이해 그룹은 기존 확정 기록으로 읽고 새 세 버튼 판정은 다시 선택해야 합니다. 이전 v1은 새 진단·전수 작문과 호환되지 않아 새 데모로 시작합니다. 이전 브라우저 저장값을 남기고 JSON 내보내기에 이전 기록도 담습니다. v1 공유 상태가 도착해도 진행 중인 v2 답안을 덮어쓰지 않습니다.
- JSON 메뉴는 전체 선택·복사와 파일 내려받기를 지원하며 격리한 복구용 원문도 포함합니다. Page 내장 화면의 인쇄·내려받기·저장이 브라우저 정책으로 제한되면 JSON을 복사하거나 단일 HTML을 로컬 브라우저에서 열어 사용하세요.
- 기록 초기화는 현재 v2 데모를 지웁니다. 내려받은 파일과 이전 v1 브라우저 기록은 삭제하지 않습니다.
- 사용자 입력과 저장값을 HTML 본문·속성에 넣을 때 문자로 처리하며 참조 ID도 검사합니다.

## 열기

브라우저에서 HTML 파일을 직접 열거나 다음처럼 로컬 HTTP 서버로 제공합니다.

```bash
python3 -m http.server 8765 --directory prototype
```

압축을 푼 최상위 폴더에서 실행합니다. 주소는 `http://localhost:8765/pilot-flow.html`입니다. 파일 직접 열기에서는 브라우저 정책에 따라 저장이 제한될 수 있습니다.
