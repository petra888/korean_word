# 상상 숲 일러스트

밝은 수채화·구아슈 질감, 민트·크림·세이지 색감을 공유하는 원본 생성 일러스트입니다. 선택한 ‘상상 숲’을 기준으로 화면 장면 세 개와 전체 배경 두 개를 추가로 생성했습니다. WebP 파일은 원본의 크기와 구도를 유지한 배포용 포맷 변환본입니다.

| 파일 | 사용처 |
| --- | --- |
| `forest-entrance.webp` | 로그인 · 숲 입구 |
| `forest-reading.webp` | 진단·이해·복습 · 책 정원과 여우 |
| `forest-writing.webp` | 작문 · 책과 연필, 토끼 |
| `forest-teacher.webp` | 교사 로그인·학습 관리 · 식물 작업실 |
| `forest-world.webp` | 전체 화면 · 4:3 숲 풍경 |
| `forest-world-mobile.webp` | 모바일 전체 화면 · 9:16 숲 풍경 |

전체 배경은 고정된 picture 요소로 제공하며, 800px 이하에서는 세로 그림을 사용합니다. 나뭇잎·나비·빛 효과는 이미지와 별개의 CSS 장식 레이어입니다. 움직임 설정은 학습 기록과 별도 키로 보관하며 동작 줄이기·탭 비활성 상태·인쇄에서는 움직임을 중지하거나 장식을 숨깁니다.

장식 이미지는 대체 텍스트를 비우고 읽을 내용은 HTML로 제공합니다. 인쇄 자료에서는 일러스트를 제외합니다. 새 이미지를 추가하거나 변경하면 자산 해시를 포함해 로컬 검증 요약을 갱신해야 합니다.
