# 독립 회귀 검증

프로젝트 루트에서 다음 명령으로 현재 HTML을 검증합니다.

```bash
node vocabulary-planning/qa/qa-fixes-v5/independent/regression.js
```

다른 HTML은 마지막 인수로 지정할 수 있습니다. 결과는 이 디렉터리의 `runtime-regression-results.json`에 기록됩니다. 실패가 있으면 종료 코드가 1입니다.

42개 검증에는 다음 내용이 포함됩니다.

- 미제출 객관 답·힌트·보기 순서, 작문·수정 초고, 확정 판정과 수동 분류의 저장 및 재시작 보존
- 잘못된 JSON 및 7종의 중첩 v2 손상에 대한 원문 격리·내보내기·안전한 재시작, 격리 저장 실패 시 원문 덮어쓰기 방지
- 이전·동일·최신 호스트 기록과 로컬 입력의 처리, 호스트 시계가 앞선 경우의 오래된 기록 재전달
- 로컬 저장 실패·복구, 동기·비동기 호스트 저장 실패·복구, 늦게 도착한 이전 저장 실패, 초기화 중 비동기 실패 및 초기화 이전 호스트 기록의 재전달 방지
- 교사 버전별 미확정 판정·코멘트·수동 분류, 재시도 중 선택의 뒤로가기·재진입·재시작 보존
- 진단 분류 개수 66가지 × 단어 위치 10가지의 총 660개 초기 배정 조건과, 실제 진단에서 단어마다 모름 1개·앎 9개인 10가지 시작 경로
- 주간·월간·분기별 10개 전체 복습, 5개 중간 저장, 문항 재사용 방지, 교사 확정 이후에만 다음 배정·차트 변경
- 기존 v2 숫자 평가 보존, 콘텐츠 수정 이전 v2 학습·분기 복습 문맥·보기·첫 답의 유지
- 저장된 메타데이터의 HTML 속성 주입 방지, 학생 문장·교사 코멘트의 이스케이프와 부모 자료의 내부 메모 제외
- 객관 선택 상태와 단어별 작문 입력의 접근성 속성, 직접 인쇄 이벤트의 최신 부모 자료 생성 및 첫 진입 시 빈 인쇄 영역 보완

`baseline-v2-fixtures.json`은 커밋 `0d7598638dac12c59e2cf7d0151b43a73f51c42a`의 HTML을 실행하여 만든 가상 입력입니다. 파일 안에 원본 HTML의 SHA-256과 생성 방법을 기록했습니다. 실제 학생 자료를 포함하지 않습니다.

검증은 Node VM과 모의 DOM·localStorage·호스트를 사용합니다. 실제 브라우저의 렌더링·키보드·보조 기술·모바일 터치·인쇄 출력, 여러 기기의 데이터 동기화, 운영 서버 인증·데이터베이스·백업은 검증하지 않았습니다. 저장 실패는 모의 예외이며 실제 용량 제한을 재현한 것은 아닙니다. 보안 검증은 생성된 HTML 속성을 확인한 것으로, 브라우저에서 스크립트가 실행되는지 시험하지 않았습니다.
