# 상상 숲 UI 변경과 로컬 검증

선택한 ‘상상 숲’의 밝은 수채화·구아슈 질감, 민트·크림·세이지 색감을 바탕으로 로그인·학생 학습·교사 화면을 수정했습니다. 원래 숲 입구 외에 여우의 책 정원, 토끼의 작문 정원, 교사용 식물 작업실을 새로 생성했습니다. 일러스트만 배경으로 붙이는 방식에 그치지 않고 카드·선택 버튼·입력창·단계 표시·차트·메뉴를 함께 구성했습니다.

v8.1에서는 화면 전체에 이어지는 데스크톱 4:3·모바일 9:16 숲 배경을 새로 생성했습니다. 풍경은 스크롤 중에도 고정되며, 카드 밖과 반투명 카드의 가장자리에 숲의 질감이 보입니다. 잎·나비·빛의 CSS 애니메이션은 장식 레이어에서만 실행합니다. 움직임 끄기·켜기, 새로고침 후 선택 유지, 기기의 동작 줄이기 설정을 실제 브라우저에서 확인했습니다.

교재 순서와 문제, 진단·60/30/10 배정, 10개 전수 작문, 교사 판정과 복습 반영, 브라우저 저장 구조는 유지합니다. 학생 계정은 `test1/test1`, 교사는 `test2/test2`입니다. 이 문서는 배포 전 로컬 검증 기록이며, 사용자가 요청한 재배포 결과는 별도의 배포 실행 기록으로 구분합니다.

## 검증

[현재 검증 요약](../validation-summary.json): 총 **165개 통과**, 실패 0개. Node VM 검증 123개, 콘텐츠 구조 검증 22개, 실제 로컬 Chromium 검사 20개입니다. VM 검증과 실제 브라우저 검증을 구분합니다.

- 학생·교사 로그인, 계정 전환, 세션·저장 오류 경계 조건, 기존 기록 복원.
- 객관식 10개와 10개 작문, 교사 검토·확정, 리포트 작성·새로고침 후 저장 유지.
- 로그인·진단·문제·리포트의 360/390/768/1280px 화면: 페이지 가로 넘침, 버튼 배치와 크기.
- 화면별 일러스트 로딩·디코딩, 오류 응답과 미처리 스크립트 오류.
- 주요 본문·보조 글자·버튼 대비 11쌍: 반투명 표면을 검정·흰색 배경 위에 합성한 보수적 계산에서도 4.5:1 이상. 일러스트 경계는 실제 스크린샷으로 확인.
- 전체 배경의 화면 크기별 선택·고정 위치·클릭 차단 없음, 실제 애니메이션 변화·일시 정지·설정 복원, 동작 줄이기 설정의 실시간 반영.
- 부모 자료 인쇄 CSS와 3쪽 PDF: 화면 장식·메뉴·내부 메모 제외, 교사 확정 메시지 포함.
- 로컬 정적 빌드와 ZIP에 HTML·manifest·일러스트만 포함하도록 수정. HTML과 이미지 해시를 함께 검사.

[디자인 브라우저 결과](browser-results.json) · [로그인 브라우저 결과](../login/browser-results.json)

[로컬 빌드 결과](build-results.json): 생성된 index.html을 로컬 HTTP로 열어 두 계정의 로그인과 일러스트 로딩을 확인했습니다. HTML 바이트와 자산 여섯 장의 해시가 검증 소스와 일치하며, 직접 업로드용 ZIP의 구성·무결성 검사도 통과했습니다. 이 결과는 원격 배포의 검증을 포함하지 않습니다.

실제 기기·실제 프린터, Safari/Firefox, 스크린리더와 실제 포인터 드래그 조작은 미검증입니다. 서버 인증·권한·저장·실제 달력별 집계와 교육 담당자의 콘텐츠 최종 승인은 이 디자인 수정의 구현 범위에 포함되지 않습니다. 원격 Vercel 주소 확인은 배포 실행 기록을 참조합니다.
