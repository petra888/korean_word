# 디자인 1·2 선택과 미래 도시 UI

디자인 1은 기존 상상 숲, 디자인 2는 선택한 ‘빛의 미래 도시’입니다. 새 방문자는 디자인 2를 보고 상단 버튼으로 자유롭게 바꿀 수 있습니다. 선택은 브라우저에 저장하며 로그인 전후, 로그아웃과 학습 초기화 후에도 유지합니다. 성별·역할에 따른 강제 배정은 하지 않습니다.

미래 도시는 전체 배경 외에 모바일 세로 풍경·지식 관측소·창작실·교사 관제실을 새로 생성했습니다. 푸른 유리·은백색·청록빛·주황 포인트를 바탕으로 각을 살린 버튼·카드, 입력창·단계 표시·진단 단어·객관식 보기·표·작문 판정·차트·메뉴를 함께 구성합니다. 장식 드론과 빛 신호는 학습 요소를 가리지 않습니다.

## 검증 범위

[디자인 전환 검증](browser-results.json)은 실제 로컬 Chromium에서 수행했습니다. 키보드 선택, 저장·새로고침, 320/360/390/768/1280px 화면과 장식의 클릭 차단 여부를 확인합니다. 로그인 입력·비밀번호 표시 상태, 미제출 답안과 작문 입력창, 교사 판정 초안·코멘트·부모 메시지가 전환 후 그대로 남고 학습 저장 revision이 바뀌지 않는지 검사합니다.

다른 탭의 디자인 선택 동기화, 독립된 움직임 선택, 동작 줄이기, 저장 실패 안내와 복구, 잘못된 값·저장 읽기 차단의 기본값 처리, 학습 초기화 후 디자인 유지도 검사합니다.

두 디자인의 [전체 흐름 검증](../forest/browser-results.json)과 [미래 도시 흐름 검증](../city/browser-results.json)은 각각 로그인·10개 객관식·10개 작문·교사 3종 판정·빨간 오답 표시·저장 복원·차트·브라우저 인쇄/PDF를 포함합니다. 작은 글자와 버튼 대비는 각 디자인에서 주요 11쌍을 검증했습니다. 실제 기기·실제 프린터·다른 브라우저 엔진·전체 스크린리더 검수는 수행하지 않았습니다.

[통합 검증 요약](../validation-summary.json)은 **184개 통과, 실패 0개**입니다. Node VM 115개, 콘텐츠 구조 22개, 실제 로컬 Chromium 47개를 구분하고 HTML·일러스트 해시와 각 검증 결과를 묶습니다. [배포용 정적 빌드 검증](build-results.json)에서는 13개 공개 파일과 두 디자인의 학생·교사 로그인·새로고침·일러스트 로딩을 추가 확인했습니다. 배포 빌드는 이 해시가 맞아야 실행됩니다. 이번 변경의 커밋·푸시·새 외부 배포는 실행하지 않았습니다.

서버 인증·학원별 권한·학생별 서버 저장·달력별 집계·문항의 교육 담당자 승인은 별도입니다. 화면 변경은 교재 어휘 순서나 문항·학습 배정·교사 판정 로직을 변경하지 않습니다.
