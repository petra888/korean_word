## 4. 인쇄 우려와 교육 검토 후보

**인쇄 우려 MP-003(P2, 실제 출력 미검증):** 앱 인쇄 버튼 전에는 print-area가 비어 있고 beforeprint 갱신도 없다. 인쇄 CSS는 화면 본문을 숨기므로 일반 Ctrl+P에서 빈 자료가 나올 가능성이 있다. 앱 인쇄 버튼의 자료 생성은 VM에서 확인했다. beforeprint에서 최신 부모 자료를 생성하고 실제 브라우저 인쇄로 확인해야 한다.

다음3개는 명백한 정답키 오류나 전문 교사 승인 결과로 단정하지 않은 **P2 교육 검토 후보**다.
