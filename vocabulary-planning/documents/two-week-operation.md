# 2주 학생 교사 수업 운영안

수정일: 2026년 10월 4일(한국 시간) · QA 개선 v5. 최신 사용자 요구에 따라 **뜻 10개와 무작위 단어 매칭 진단 → 혼합 4지선다 빈칸 10문항 → 전체 10단어 작문 → 교사 3버튼 판정과 자동 다음 분류 확인 후 보충**으로 운영을 구체화했다. 큰 학습 흐름은 진단·계획, 이해·추론, 표현·수정, 복습·재확인이다. 사용자가 요청한 학습 방식은 반영하되 인원·요일·시간·평가 처리시간은 검증할 가정이다.

기존 3가지 자기 선택은 뜻 매칭 진단으로 교체한다. 기존의 회당 객관형 9개·초고 1개 혼합 배정도 **객관형 10개와 별도 전수 작문**으로 바꾼다. 개발 전 운영안이며 실제 학생의 결과나 확정 납품 일정이 아니다.

## 1 운영 전제와 시간 변화

| 항목 | 이번 제안 | 아직 확인할 내용 |
| --- | --- | --- |
| 도입 규모 | 학원 1곳, 학생 30명 | 실제 학원·반·인원 |
| 학생층 | 초등 고학년 우선, 일부 중학생 사용성 확인 | 실제 학년·읽기·입력 수준 |
| 기기 | PC·태블릿 웹 브라우저 | 학원 기기와 가정 접근 여부 |
| 정규 운영 | 월·수·금 주 3회, 2주 6회 | 학원 시간표에 맞춰 요일 조정 |
| 이해·추론 | 회당 혼합 4지선다 빈칸 10문항, 총 60문항 | 난도·문항 공급·실제 소요시간 |
| 작문 | 10단어 각각 한 문장, 첫주 3회에 4·3·3개 제출, 둘째주는 수정·객관형·복습 | 입력 부담·교사 처리량 |
| 피드백 | 다음 수업 전까지 교사 검토 후 수정 | 담당 교사 수·검토 기한 |
| 주간 복습 | 각 주 실제 학습 10단어 전수 확인 | 별도 복습 시간 12분 × 2회 확보 |
| 부모 자료 | 교사 확인 후 PDF, 기존 학원 채널로 전달 | 작성 주기·직접 메시지 시간 |

작문이 6개에서 모든 단어의 10개로 늘고 교사 수정도 늘었다. 첫 회 진단까지 포함한 이번 시간 산정은 **회당 12~42분**, 주간 복습 24분은 별도다. 첫주는 전수 초고를 모두 제출하므로 회당42·39·36분이고 둘째주는21·12·12분이다. 기존 주 3회 15~20분 가정은 이 범위 전체를 수용하기 어렵다. 학습 범위를 유지하면서 시간을 늘리거나, 진단·작문·복습 시간을 별도 블록으로 확보하는 방식으로 운영해야 한다.

이 문서의 2주는 4주 파일럿 중 학습 구간 2주다. 날짜는 상대 요일이며 실제 일정은 학원이 정한다.

## 2 사용할 10개 단어와 진단 분류 예시

| 원문 콘텐츠 ID | 단어 | 가상 최초 진단 분류 | 원문 뜻풀이 |
| --- | --- | --- | --- |
| W0001 | 까탈 | 모름 | 일이 순조롭지 않게 방해하는 일 |
| W0002 | 깜냥 | 모름 | 일을 해낼 만한 본인 능력 |
| W0003 | 달포 | 모름 | 한 달이 조금 넘는 기간 |
| W0004 | 말미 | 모름 | 다른 일로 얻게 되는 여유 |
| W0005 | 선잠 | 모름 | 깊이 들지 못하고 깬 잠 |
| W0006 | 강단있는 | 애매함 | 굳세고 강하게 결단하는 힘 |
| W0007 | 격의 | 애매함 | 속마음을 터놓지 않아 느끼는 거리감 |
| W0008 | 융통성 | 애매함 | 형세에 따라 일을 처리하는 재주 |
| W0009 | 굴지 | 앎 | 손가락을 꼽을 만큼 뛰어남 |
| W0010 | 기탄없이 | 앎 | 꺼리거나 사양하지 않고 |

단어를 임의로 고르지 않고 **원본 PDF 첫 페이지의 1~10번 W0001~W0010 순서**로 사용한다. 가상 분포는 첫5개 모름·다음3개 애매함·마지막2개 앎이며, 실제 진단으로 달라진다. 실제 학생의 진단 결과를 이 분포로 강제하지 않는다. 원문 표제어·뜻풀이와 순서를 보존하며 쉬운 풀이·교정은 별도 버전으로 승인한다. ‘강단있는’의 표제어·활용형 분리와 ‘융통성’의 대응 복습행 의미 불일치는 검수 대상이다. 오류 후보 때문에 단어를 건너뛰거나 다른 단어로 임의 교체하지 않는다. 원문 콘텐츠 ID는 출처 추적용이며 승인 의미 ID와 버전은 검수 이후 연결한다.

진단에서는 승인된 쉬운 뜻 10개와 무작위 순서의 단어 10개를 매칭한다. 각 뜻에서 단어 또는 ‘모른다’를 선택한다. 무작위 순서와 최초 응답·정답 안내 여부를 저장한다.

| 진단 행동 | 최초 배정용 분류 | 기록·안내 |
| --- | --- | --- |
| 정답 안내 전에 첫 답을 맞힘 | 앎 | 최초 독립 정답과 당시 배정 그룹 기록 |
| 첫 답이 틀림 | 애매함 | 최초 오답을 유지하고 정답·뜻을 안내 |
| ‘모른다’를 선택 | 모름 | 모름 응답을 저장한 뒤 해당 정답을 자동 안내 |
| 정답을 본 뒤 맞힘·재시도 | 최초 그룹 유지, 재검증 필요 | 도움 후 성공 기록. 독립 정답이나 확정 익힘으로 올리지 않음 |
| 아직 선택하지 않음 | 미응답 | 자동으로 모름이나 정답 처리하지 않음 |

진단이 뜻을 제시한다는 점은 진단 방식의 특성이다. 뜻 매칭 진단 응답만으로 기간별 ‘실제로 학습한 단어’ 집합이나 정규 완료량을 늘리지 않는다. 진단 뒤 객관형 학습 응답이나 초고를 제출한 단어를 실제 학습 집합에 넣는다. 최초 진단과 배정 당시 그룹을 보존하고 후속 교사 판정은 새 기록으로 연결한다. 한 번의 진단 정답은 숙달 완료를 뜻하지 않는다.

## 3 정규 객관형과 전수 작문의 구분

객관형 집중 활동은 매회 **혼합 4지선다 빈칸 10문항**, 6회 총 60문항이다. 뜻 구별·문맥 추론·유사어 비교를 서로 다른 문맥의 빈칸 질문으로 섞고, 각 문항에는 승인된 선택지 4개를 사용한다. 선택지와 문항 순서는 무작위화하되 정답 위치·의미·버전·표시 순서와 응답을 재현할 수 있게 기록한다.

객관형의 중심 목표 단어에 모름 60%·애매함 30%·앎 10%를 적용한다. 같은 문항의 힌트와 재시도는 새 활동으로 세지 않는다. 한 문항에 비교 단어가 여러 개 나와도 비중에는 중심 단어 하나만 귀속한다.

| 회차 | 모름 6객관형 | 애매함 3객관형 | 앎 1객관형 | 별도 전수 초고 |
| --- | --- | --- | --- | --- |
| 1회 / 1주 월 | 모름 5단어 각 1개 + 까탈 새 문맥 1개 | 강단있는·격의·융통성 각 1개 | 굴지 | 까탈·깜냥·달포·말미 4개 |
| 2회 / 1주 수 | 모름 5단어 각 1개 + 깜냥 새 문맥 1개 | 강단있는·격의·융통성 각 1개 | 기탄없이 | 선잠·강단있는·격의 3개 |
| 3회 / 1주 금 | 모름 5단어 각 1개 + 달포 새 문맥 1개 | 강단있는·격의·융통성 각 1개 | 굴지 | 융통성·굴지·기탄없이 3개 |
| 4회 / 2주 월 | 모름 5단어 각 1개 + 말미 새 문맥 1개 | 강단있는·격의·융통성 각 1개 | 기탄없이 | 신규 초고 없음, 이전 피드백 수정 |
| 5회 / 2주 수 | 모름 5단어 각 1개 + 선잠 새 문맥 1개 | 강단있는·격의·융통성 각 1개 | 굴지 | 신규 초고 없음 |
| 6회 / 2주 금 | 모름 5단어 각 1개 + 까탈 다른 문맥 1개 | 강단있는·격의·융통성 각 1개 | 기탄없이 | 신규 초고 없음 |
| 합계 | 36객관형 | 18객관형 | 6객관형 | 10단어 각각 초고 1개 |

이 표는 진단 그룹이 고정된 가상 배정 예시다. 두 주 모두 실제 학습 10단어가 등장하고, 초고는 원문 순서대로 첫주4·3·3개로 제출해10개를 모두 작성한 뒤 주간 전수 복습으로 진입한다. 둘째주는 앞선 초고 수정과 객관형·복습을 진행한다. 전체초고 제출과 교사 판정·수정 완료는 별개다. 교사 검토 대기는 전수 복습 진입을 막지 않으며 마지막3개 수정은 둘째주1회로 이어진다. 실제 교사 판정으로 그룹이 바뀌면 다음 객관형 배정부터 반영한다. 지난 그룹 비중은 다시 계산하지 않는다.

**정규 객관형 60개와 전수 초고 10개는 서로 다른 과제이며 합계 70개 제출 대상이다.** 60·30·10은 객관형 집중 및 후속 보충에 적용하고, 모든 단어를 쓰는 전수 작문에는 적용하지 않는다. 초고마다 하나의 목표 단어를 의미에 맞게 활용한 완결된 문장을 제출한다. 단어별 기본·대체 질문을 2개씩 준비하면 20개 질문이지만, 20개 초고를 의무 제출한다는 뜻은 아니다. 한 질문을 선택해 10개 초고를 제출하며 수정은 기존 초고 이력이다.

## 4 콘텐츠 수요와 부족 처리

| 문항 은행 | 제작 수요 | 운영 사용 |
| --- | --- | --- |
| 집중 객관형 | 10단어 × 9개 = 90개 | 6회에 60개 사용, 같은 문항 재사용 금지 |
| 사전·사후·지연 평가 | 10개 × 3세트 = 30개 | 평가별 새 문맥, 학습·복습과 분리 |
| 주간 전수 복습 | 10개 × 2주 = 20개 | 각 주 다른 문맥으로 전수 확인 |
| 월간 전수 복습 | 10개 × 1세트 = 10개 | 월간 대상에 해당하는 새 문맥 |
| 분기 전수 복습 | 10개 × 1세트 = 10개 | 분기 대상에 해당하는 새 문맥 |
| **객관형 총량** | **160개** | **위상별 사용 이력 유지** |
| 전수 작문 질문 | 10단어 × 기본·대체 = 20개 | 학생 초고는 고유 단어당 1개, 총 10개 |

단어당 연습 9개 공급은 가상 그룹별 모름 45개·애매함 27개·앎 18개를 제공해 정규 수요 36·18·6을 충족한다. 예시에서 까탈 8개, 다른 모름 단어 각 7개, 애매함 각 6개, 앎 각 3개를 사용한다. 미사용 은행의 첫 회차는 세 그룹 단어 수의 66조합 모두 10문항을 공급해야 한다. 모름 1개·애매함 0개·앎 9개라면 모름 9문항과 앎 1문항으로 시작한다. 기존 8개 은행에서 이 조건이 막히던 문제를 새 연습 1개씩 추가해 해결한다. 추가 제작량은 은행의 공급량이며 2주 필수 제출 70개·학생 시간 186분은 바꾸지 않는다.

가상 그룹이 유지되면 정규 이후 미사용 집중 문항은 모름 9개·애매함 9개·앎 12개다. 첫 보충 10개를 6·3·1로 배정한 뒤에는 3·6·11개가 남으므로 두 번째 같은 비중의 보충은 모름 문항이 3개 부족하다. **남은 총 문항 수만 보고 보충 가능을 선언하지 않는다.** 당시 그룹별 미사용 승인 문항을 계산해 새 변형을 승인하거나 일반 제품에서는 교사 승인 재배분·보류한다. 이번 고정 공급 시제품은 부족하면 시작을 보류한다. 이미 사용한 동일 문항, 평가 문항, 전수 복습 문항을 비중 채우기용 집중 문항으로 돌려 쓰지 않는다.

특정 학생의 분류 쏠림, 반복 보충, 상태 변경에 따라 9개 은행도 부족할 수 있다. 공급량 부족·재배분 사유·보류 수·수정된 계획 분모를 표시한다. 파일럿 확대용 30개 어휘은행과 추가 변형은 별도 제작·승인한다. 문항 초안 수는 승인·출시 완료를 뜻하지 않는다.

## 5 학생과 교사의 2주 시간표

학생 시간의 중심값은 진단 10분, 객관형 문항당 1분, 초고당 5분, 피드백 확인·수정당 3분, 계획·정리 각 1분이다. 입력·읽기 속도에 따라 달라질 검증 가정이다.

| 시점 | 학생이 하는 일 | 학생 시간 가정 | 교사가 하는 일 |
| --- | --- | --- | --- |
| 시작 전 | 개인 계정·기기 접근 확인 | 본표 합계 제외 | 소속 학원·반·학생 권한 확인, 승인 콘텐츠와 과제 배정 |
| 1주 월 / 1회 | 뜻 매칭 진단10 → 계획 → 객관10 → 초고4 → 정리 | 10 + 1 + 10 + 20 + 1 = 42분 | 새4초고 의미·상황·완결성 판정, 다음 수업 전 피드백 |
| 1주 수 / 2회 | 계획 → 객관10 → 초고3 → 이전4초고 수정 → 정리 | 1 + 10 + 15 + 12 + 1 = 39분 | 이전 수정 확인, 새3초고 판정 |
| 1주 금 / 3회 | 계획 → 객관10 → 초고3 → 이전3초고 수정 → 정리 | 1 + 10 + 15 + 9 + 1 = 36분 | 이전 수정과 마지막3초고 판정, 전체10초고 제출 확인 |
| 1주 복습일 | 전체초고10개 제출 후 주간 새 문맥 전수5 + 5 → 결과·판정 상태 확인 | 5 + 5 + 2 = 12분 추가 | 검토 대기는 진입 차단하지 않음. 전수 범위·누락·오개념 확인, 리포트 |
| 2주 월 / 4회 | 계획 → 객관10 → 마지막3초고 피드백 수정 → 정리 | 1 + 10 + 9 + 1 = 21분 | 수정본 확인, 표현 판정 확정 또는 추가 지도 |
| 2주 수 / 5회 | 계획 → 객관10 → 정리 | 1 + 10 + 1 = 12분 | 객관형 수행·상태 변경 확인, 추가 수정이 있으면 별도 지도 |
| 2주 금 / 6회 | 계획 → 객관10 → 정리 | 1 + 10 + 1 = 12분 | 2주 객관형·10단어 표현·복습 추이 확인 |
| 2주 복습일 | 1주와 다른 문맥 전수5 + 5 → 결과·판정 확인 | 12분 추가 | 주간 평가·직접 부모 메시지·다음 계획 작성 |
| 교사 판정 및 전수 확인 후 필요할 때 | 새 승인 문항으로 보충10활동 | 10분 × 최대2묶음 추가 가정 | 근거에 따른 분류, 공급 확인 후 배정·재배분·보류 |

교사 판정 전에는 제출 완료와 검토 대기를 구분한다. 초고에 목표 어휘가 들어 있다는 이유만으로 의미 정답을 확정하지 않는다. 교사는 작문을 정답·오답·검토(애매) 중 하나로 판정한다. 판정은 필수이고 코멘트는 선택이다. 같은 현재 묶음에서 해당 단어를 중심 목표로 한 유효 첫 객관 응답이 하나 이상 있고 모두 정답이며 작문도 정답이면 다음 학습 분류를 앎으로 자동 제안한다. 힌트 사용은 별도 도움 근거로 표시하며 앎 제안을 막는 조건은 아니다. 작문 오답은 모름, 작문 검토(애매)는 애매함이다. 작문 정답이라도 객관 첫 응답에 오답이 있거나 객관 근거가 없으면 애매함·재확인으로 제안한다. 교사는 자동 제안을 확인하고 다음 분류를 앎·애매함·모름 중 수정한 뒤 확정할 수 있다. 수동 수정과 설명은 선택이며 확정 수동 분류가 자동 제안보다 우선한다. 판정 근거 스냅샷과 확정 시각을 기록해 다음 배정부터 반영한다. 잘 쓴 문장 하나로 장기 익힘까지 자동 확정하지 않는다.

일상 화면은 진단·계획 확인, 객관형 집중학습, 단어별 작문, 이전 피드백 수정·정리로 이어진다. 진단은 최초 묶음에서 하고 동일 묶음에서는 기록을 확인한다. 교사 검토가 늦어도 초고를 보존하고 다른 학습은 계속한다. 추가 수정이 필요하면 같은 작문 ID에서 이어가고 실제 시간을 따로 측정한다.

복습일은 별도 학원 시간이나 기기 접근이 확인된 가정 시간으로 확보한다. 주말 접속을 확정 의무로 취급하지 않는다. 종료 전 주간 복습을 시작하면 진행 중 기간·집계 시점을 표시하고, 종료 시 대상·버전을 고정한다. 지연 제출로 대상이 늘면 기존 응답을 유지하면서 추가 단어와 새 분모를 표시한다.

## 7 주간 월간 분기 복습이 겹칠 때

전체 복습은 실제 객관형 응답 또는 초고를 제출한 승인 의미를 기간별로 중복 제거해 만든다. 진단·뜻 열람만 한 단어는 실제 학습 집합에 넣지 않는다. 이번 예시는 두 주 모두 대상10개다. 월간·분기 대상은 주간 수를 더하지 않고 해당 기간 실제 학습 기록에서 다시 중복 제거한다.

일간·주간·월간에서 진단 상태, 객관형 계획·완료와 그룹 비중, 전수 작문10개 중 제출·교사판정·수정 상태, 기간 전수 진도, 조건부 보충을 구분한다. 초고10개 제출이나 진단10개 응답을 ‘10단어 익힘’으로 쓰지 않는다. 교사는 이해·추론·작문·태도를 실제 근거로 평가하고 직접 부모 메시지를 작성한다. 태도를 관찰하지 않았으면 미평가로 남긴다.

PDF는 해당 학생 한 명의 기록만 담고 교사명·확인일·기간·집계 시점·버전을 고정한다. 늦은 교사 판정은 갱신본으로 출력하고 이미 전달한PDF를 바꾸지 않는다. 자동 발송·부모 계정은 후속 범위이며 익명 홍보 요약은 별도 검토한다.

## 10 준비 완료 기준과 미확정 사항

- 콘텐츠: 원본 순서의 첫10단어 W0001~W0010의 의미·뜻 매칭·4지선다 빈칸160개·단어별 기본/대체 작문20개를 국어 담당자가 승인한다. 단어별·그룹별 미사용 공급을 확인하고 보충용 새 변형과30개 확대은행을 준비한다.
- 수업: 진단·객관형·10단어 작문·10건 수정·주간 복습을 위한 기본186분을 확보하거나 각 블록을 별도 시간으로 배치한다. 기존15~20분 가정을 확정 운영 조건으로 쓰지 않는다.
- 교사: 학생30명 반 기준 첫주960분·둘째주60분의 발생주 예산 외 수정 재검토·검수·복습 관리·지원 시간을 확보한다. 담당교사와 다음 수업 전 피드백 기한을 확인한다.
- 데이터: 진단 최초 응답과정답 노출, 객관형 배정 그룹,10단어 초고·판정·수정, 저장·권한·중복 제출·기간 집계·PDF 일치를 검수한다.
- 파일럿: 실제 도입 학원·학생·기기·교육 승인자, 사전·사후·지연 일정과 부모PDF 확인 담당자를 지정한다.

사용자 결정이 남은 항목은 도입 학원·학생층·인원, 장소·기기·수업 시간, 교재 권한과콘텐츠 승인자, 교사 가용 시간·피드백 기한, 부모 전달 주기·채널, 디자인·납품·맞춤 범위, 예산·목표일·운영 담당자·계약 조건이다. 진행 승인과이 항목들의 확정은 구분한다. 상세 시간표와 가정은 `planning/two-week-operation.csv`, `planning/assumptions.json`에 보관한다.
