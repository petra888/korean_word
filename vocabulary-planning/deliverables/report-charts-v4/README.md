# 교사 평가·부모 자료 차트 개선 자료 v4

2026년 10월 4일 개정. 교사 평가 화면과 부모 미리보기·인쇄 자료에 같은 집계의 도넛 차트를 제공합니다. 기존 작문 3버튼·자동 배정·교사 수정, 오답 빨간 표시와 복습 답안 상세를 유지합니다. 브라우저 저장 형식은 v2입니다.

## 차트와 집계

- **단어 이해 현황:** 아는 단어·애매한 단어·모르는 단어·교사 확인 대기. 최신 확정 교사 이해 그룹을 우선하며, 교사 확정이 없으면 확인 대기로 표시합니다. 최초 진단과 수행에 따른 잠정 분류는 기존 단어별 표와 다음 배정에서 확인합니다.
- **작문 평가 결과:** 정답·오답·검토(애매)·평가 대기. 단어별 최신 확정 세 버튼 판정으로 집계합니다. 과거 숫자 배점을 새 정답·오답으로 환산하지 않습니다.
- 같은 의미 ID를 한 번만 집계하고, 차트 중심에 전체 단어 수, 범례에 실제 개수와 비율을 함께 표시합니다. 현재 시제품 대상은 교재 순서 첫 10개입니다.
- 새 수정본은 이전 확정 평가를 바꾸지 않습니다. 수정본 재검토 대기를 별도로 표시하며 교사가 다시 확정한 뒤 반영합니다.
- 정규 객관 문제와 전수 작문 완료 진도는 각각 표시합니다. 추가 복습할 단어 목록과 기존 교사 종합 평가·부모 메시지를 함께 제공합니다.
- 60·30·10은 다음 학습의 배정 원칙으로 별도 표시합니다. 이전 확정 자료의 차트 스냅샷이 있을 때만 아는 단어 수의 증감을 비교하며, 실제 지난주·달력 데이터를 임의로 만들지 않습니다.

## 확인할 화면

압축을 푼 최상위 폴더의 `prototype/pilot-flow.html`을 브라우저에서 엽니다. 학생 답안과 작문을 제출하고 교사 작문 판정을 확정한 뒤, **교사 평가·부모 자료**에서 차트와 미리보기·인쇄를 확인합니다. 평가 전에는 확인·평가 대기가 표시됩니다.

차트는 SVG의 명시적 색과 텍스트로 작성해 외부 차트 라이브러리 없이 열 수 있습니다. 색을 구분하기 어려워도 항목명·개수·비율로 읽을 수 있습니다. 부모 출력에는 내부 지도 메모가 포함되지 않으며 자동 발송하지 않습니다.

## 포함 자료와 검증 범위

최신 HTML·README, 관련 PRD·개발 명세·검수표, PDF 문서, 교재 첫 10개 콘텐츠 JSON·CSV를 제공합니다. 교재 전체450학습행과45묶음의 원문 순서도 유지합니다. 모든 콘텐츠는 교육 담당자 최종 승인 전입니다.

`planning/prototype-validation.json`은 Node VM·모의 DOM의 동작 검증 기록입니다. `planning/chart-svg-render-validation.json`에는 실제 SVG를 MuPDF로 이미지화한 가상 기록의 비율·100%·0건 검증 결과도 있습니다. 실제 브라우저·마우스·모바일·인쇄 동작은 현재 환경의 브라우저·소켓 제한으로 미검증입니다. 실제 계정·서버 권한·저장·달력별 리포트 집계를 구현한 납품 서비스가 아닙니다.

PDF는 문서 렌더러로 생성하고 한글 글꼴 내장과 검색 가능한 본문·원본 일치를 확인합니다. 파일별 SHA256은 `deliverables/report-charts-v4/package-manifest.json`에 있습니다.

node qa/development-readiness/prototype-vm-check.js
