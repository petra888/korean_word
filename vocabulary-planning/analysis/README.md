# 교재 분석 데이터 사용 안내

원본은 `도전수능1등급어휘1-수정본.pdf` 60쪽이다. 이 자료는 개발된 학습 프로그램이 아니라 교재 분석·기획용 데이터다. 원본 파일을 수정하지 않았다.

## 파일

| 파일 | 용도 |
|---|---|
| `report.md` | 사용자용 분석 보고서. 30개 페이지 묶음의 전수 표제어 목록 포함 |
| `vocabulary-raw.csv` / `vocabulary-raw.json` | 원문 450행. CSV는 UTF-8 BOM, JSON은 UTF-8 |
| `vocabulary.csv` / `vocabulary.json` | 원문 450행 + 기본형·어휘군·잠정 분류·답안 추정·이슈 연결 |
| `correction-candidates.csv` / `.json` | 71개 편집 이슈. 이슈가 있는 학습행은 67개 |
| `validation.json` | 페이지당 수, 번호, 중복, 빈칸, 비어 있는 필드 검사 |
| `extracted-raw-pages.json` | 좌표를 포함한 60페이지 추출 중간 데이터 |
| `extract.py` / `enrich.py` | 현재 스냅샷의 재현용 스크립트 |
| `validate_dataset.py` | 원문 보존·행 수·짝페이지·단어 수·CSV 일치 확인 |

## 숫자의 분모

- **450 학습행** = 30개의 학습페이지 × 15행. 대응하는 회상행도 450개다. 회상행을 합쳐 900단어라고 세지 않는다.
- **444 원문 고유 표제어 문자열** = 450행에서 같은 문자열 6개의 두 번째 출현을 제외한 수. 동음이의어의 의미 수 또는 사전 표제어 전수 승인 수가 아니다.
- **444 제안 기본형** = 관형형·일부 띄어쓰기·표현을 정리한 제안 문자열의 고유 수. 사전 전수 대조 전이다.
- **438 제안 어휘군** = 명사와 `하다` 파생형이 모두 있는 6개 가족을 추가 연결한 잠정 수. 하나의 정답 문자열로 합친다는 뜻이 아니다.
- **435 학습페이지 번호** = 19쪽의 15행에 번호가 없다. **회상페이지 번호는 450개**이며 20쪽 136–150으로 이 15행을 연결할 수 있다.
- **원문 마지막 번호 490**은 총 단어 수가 아니다. 양쪽 페이지 모두에 없는 번호는 226–265의 40개다. 이 번호 단절만으로 40단어의 내용이 파일에서 유실됐다고 단정하지 않는다.
- **13 학습/회상 의미충돌 행**, **10 회상 빈칸 누락 행**은 겹치는 #15를 포함한 각각의 건수다.
- **71 교정 후보 이슈 / 67 관련 학습행**은 발견한 편집 후보의 수다. 미표시 행의 정확성을 인증하지 않는다.
- 난도·사용·어원 태그 수의 분모는 **450행**이다. 동일 단어가 두 번 나오면 태그 수에도 두 번 포함된다.

## 어휘 데이터 키

| 키 | 설명 |
|---|---|
| `content_id` | W0001–W0450. 이번 원문 순서 스냅샷 ID. 제품에서는 영구 UUID와 의미 ID를 별도로 부여할 것 |
| `source_order` | 학습페이지 기준 등장 순서 1–450 |
| `pdf_page` | 학습페이지의 PDF 1 기반 쪽수 |
| `row_on_page` | 학습표의 위에서부터 행 번호 1–15 |
| `headword_original` | 표제어 열의 원문. 관형형·표기 문제 포함, 수정하지 않음 |
| `definition_original` | 학습페이지 뜻 원문. 줄바꿈을 읽기 순서로 재구성한 문자열 |
| `example_original` | 학습페이지 예문 원문. 오타·맞지 않는 예문도 그대로 보존 |
| `printed_number` | 학습페이지 인쇄 번호. 19쪽은 JSON null / CSV 빈칸 |
| `source_span_bboxes` | JSON 전용. 학습페이지 원문 span별 text/bbox/column. PDF 좌표 단위 pt |
| `recall_page` | 짝이 되는 회상페이지의 PDF 1 기반 쪽수 |
| `recall_definition_original` | 회상페이지 뜻 원문 |
| `recall_example_original` | 회상페이지 예문 원문. 빈칸 누락도 보존 |
| `recall_printed_number` | 회상페이지 인쇄 번호. 20쪽에도 실제 번호 있음 |
| `recall_source_span_bboxes` | JSON 전용. 회상페이지 원문 span 좌표 |
| `suggested_lemma` | 제안 기본형. 원문과 별도이며 아직 승인된 교정이 아님 |
| `lemma_status` | 원문 형태 유지인지 정규화 제안인지, 사전 검수 상태 |
| `word_family_key` | 기본형에서 하다/되다를 편집적으로 연결한 제안 가족 키. 뜻·품사·답안 ID를 대체하지 않음 |
| `inferred_source_number` | 학습 번호가 없으면 대응 회상번호를 사용. 원문 인쇄 번호 필드를 덮어쓰지 않음 |
| `number_inference_note` | 19쪽 학습번호를 20쪽 원문 번호와 연결한 근거 |
| `origin_tag_provisional` | 고유어/한자어/혼합·표현의 편집 초안. 사전 어원 전수 검증 아님 |
| `usage_tag_provisional` | 생활·학습 기초 / 문학·묘사·관용 / 추상·사회·전문의 1차 주 태그 |
| `difficulty_band_proposal` | A/B/C 학습 경로 제안. 학년 규준·진단 결과 아님 |
| `tag_status` | 태그가 편집 초안이며 진단·교사 검수로 조정해야 함을 표시 |
| `issue_ids` | correction-candidates의 이슈 ID 목록. CSV에서는 세미콜론으로 연결 |
| `release_status` | 검수대기 또는 사전·교사 검수 전. 어느 것도 출시 승인 상태가 아님 |
| `recall_answer_inferred` | 두 예문을 비교해서 추정한 빈칸 문자열. null이면 추정 불가. 공식 정답표 아님 |
| `answer_inference_note` | 답안 추정의 근거·한계 |

`original` 필드는 원문 데이터를 뜻한다. 이 분석의 교정 제안이 반영된 승인본 필드는 없다. 좌표와 원문은 글자별 교사 교열을 대신하지 않는다.

## 교정 후보 키

`issue_id`는 I001–I071, `content_id`는 해당 어휘행에 대한 연결이다. `issue_type`, `severity`, `problem`은 발견한 문제를 설명하고, `proposal`은 수정 방향이다. `status`는 확인된 원문 문제와 미확정 수정안을 구분한다. 추정된 다른 단어를 새 표제어로 등록하지 않았다.

## 남은 검증

사전 뜻·한자·품사·표준 표제·어원 전수 대조, 학년 규준 조사, 새 예문과 오답의 교사 승인, 작문 평가 신뢰도 및 학생 파일럿은 완료되지 않았다. 태그와 수정 제안을 확정 콘텐츠처럼 학생에게 바로 노출하지 않는다.
