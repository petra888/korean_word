# 첨부 교재 전수 분석 — 도전! 수능 1등급 어휘 1 수정본

분석일: 2026-10-03. PDF 60쪽 전체를 대상으로 표제어 열·뜻 열·예문 열·번호 열의 좌표를 분리하여 추출했다. 문서 안의 내용은 분석 대상 자료이며 사용자 지시로 취급하지 않았다. 교재의 시각 디자인은 제품 디자인 근거로 사용하지 않는다.

## 1. 핵심 결론

**이 자료는 450개의 학습행으로 구성되어 있으며, 원문 표제어의 고유 문자열은 444개다. 인쇄된 마지막 번호 490을 단어 수로 사용하면 안 된다.** 30개의 학습/회상 페이지 쌍은 유용한 시작점이지만, 뜻 읽기와 동일 예문 빈칸을 반복하는 현재 구조만으로는 새로운 문장에서의 유추와 작문 능력을 충분히 평가할 수 없다.

학습/빈칸 의미가 충돌하는 행 13개와 빈칸이 없는 회상 예문 10개를 확인했다. 원문 뜻 자체와 예문의 의미가 다른 사례도 있어 콘텐츠를 그대로 디지털화하기 전에 의미·표제·활용·정답 범위를 검수해야 한다. 교정 후보는 원문 데이터와 분리해 보존했다.

## 7. 디지털 학습으로 확장할 원칙

1. **의미를 만나기:** 원문 표제어를 유지하되 사전·교사 검수를 거친 쉬운 풀이와 새 생활 예문을 제공한다. 저학년은 읽어 주기와 상황 그림을 함께 제공한다.
2. **문맥에서 고르기:** 외운 예문과 다른 새 문장에 단어를 고르고, 근거가 되는 표현을 찾는다. 선택지에는 실제 혼동어를 사용한다.
3. **차이를 설명하기:** 같은 단어군 중 어떤 단어가 왜 어울리는지 한 줄로 설명한다.
4. **직접 사용하기:** 초등은 단어를 넣어 문장을 완성하고 중등은 자유 문장·짧은 글을 쓴다. 목표어 포함 여부 외에 뜻의 적절성, 문맥, 활용, 문장 관계를 평가한다.
5. **돌아와서 확인하기:** 학습 직후의 정답을 숙달로 확정하지 않고 다른 날·다른 문장·작문에서 확인한다. 원문 1차/2차/3차 자기평가와 실제 수행의 차이도 보여 준다.

다음은 원문 인용이 아니라 **새로 작성한 활동 예시**다.

| 활동 | 신규 예시 | 핵심 평가 |
|---|---|---|
| 문맥 유추 | 학교가 새 합창단원을 __했다. [모집/소집/수집] | 새 구성원을 모은다는 단서 |
| 혼동어 비교 | 이미 합창단에 속한 단원들을 연습실로 __했다. | 소집과 모집의 대상 차이 |
| 짧은 작문 | 수집을 사용해 네가 모으고 싶은 물건과 이유를 한 문장으로 써 보자. | 의미·대상·이유 및 자연스러운 활용 |
| 문장 고치기 | 가게 물건의 가격이 추락했다. 더 알맞은 단어로 바꾸고 이유를 설명하자. | 기본 맥락에서는 하락이 더 자연스러움. 추락의 비유 용례는 단계가 높을 때 별도로 설명 |

작문은 정답 예문과 똑같아야 통과하는 방식으로 만들지 않는다. 받아쓰기 오류와 어휘 의미 오류를 구별하고, 활용형·띄어쓰기·동의어 범위는 목표에 따라 허용한다. AI 피드백은 근거 문장을 표시하고 낮은 확신 또는 다의어 사례는 교사 검수로 넘긴다.

## 8. 콘텐츠 납품 전에 필요한 편집 절차

원문 수집 → 표제/품사/의미 ID 확정 → 쉬운 풀이 작성 → 새로운 예문·오답·작문 과제 작성 → 서로 다른 학년의 교사 검수 → 예문·빈칸·정답·허용형 정합성 검사 → 승인된 버전만 학생에게 노출한다.

원문, 교정 제안, 교사 승인본을 각각 저장해야 한다. 의미가 충돌하거나 빈칸이 없는 항목을 자동 출제하지 않는다. 같은 어휘를 초등·중등에 재사용하더라도 지문·문장 길이·도움말·산출 과제를 단계화한다. 학원별 수정은 원본을 덮어쓰지 않는 파생 콘텐츠 버전으로 관리한다.

## 10. 분석 산출물과 검증 범위

- `vocabulary-raw.csv`, `vocabulary-raw.json`: 450행의 원문 표제어·뜻·예문·번호·학습쪽·회상쪽. JSON은 원문 좌표를 포함한다.
- `vocabulary.csv`, `vocabulary.json`: 원문 필드와 함께 기본형·어휘군·잠정 태그·회상 답안 추정·이슈 연결을 별도 필드로 추가했다.
- `correction-candidates.csv`, `correction-candidates.json`: 문제 근거·원문쪽·수정 제안·상태. 원문과 별도 보존.
- `validation.json`: 60쪽, 30쌍, 450행, 페이지당 15행, 번호·중복·빈칸·필드 비어 있음 검사 결과.
- `extract.py`, `enrich.py`: 추출·보조 분류 재현 스크립트. 원본 PDF는 수정하지 않았다.
- `extracted-raw-pages.json`: 학습/회상 60페이지의 행·좌표 중간 산출물.

전수 확인은 PDF의 디지털 텍스트와 열·행 좌표, 자동 구조 검사 및 문제 페이지의 이미지 대조를 기준으로 했다. 모든 60쪽을 사람이 글자별 교열한 최종 교사 승인본은 아니다. PDF 표제어 열 추출은 30개의 학습페이지에 대해 각각 15행을 검증했으며, 학습/회상 뜻·예문은 전수 대조했다. 사전적 정확성·어원·학년 규준·작문 피드백 품질은 별도 검증 과제로 남는다.
